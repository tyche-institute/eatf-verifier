# EATF v0.6.0 — hybrid ML-DSA signing and offline downgrade lab

This release adds a practical, public post-quantum migration path to the EATF
evidence-package toolkit.

## Highlights

- hybrid classical + ML-DSA-65 signing in the TypeScript signer;
- matching transitional and PQC-required policy modes in both public verifiers;
- downgrade, tamper, incomplete-pair, and cross-language conformance coverage;
- six prepared offline workshop packages with expected results and 45-, 60-,
  and 90-minute run sheets;
- a one-page archive-migration worksheet in Markdown, HTML, and PDF; and
- a deterministic conference bundle with SHA-256 checksum.

The software and workshop materials are research artifacts, not a trust service,
certification, or production-readiness claim. Review the documented limitations
before operational use.
